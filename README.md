# EverQuestPlates

See at a glance which mobs you still need for your quests in **World of Warcraft: Forever**.

By [Ctrl+Z Creations](https://github.com/Ctrl-Z-Creations).

## Install

Get it from CurseForge or Wago, or download the zip from [Releases](https://github.com/Ctrl-Z-Creations/EverQuestPlates/releases) and unzip it into your WoW: Forever `Interface\AddOns` folder.

## Features

- A gold **!** on the nameplate of every mob you need for a quest
- Your progress right next to it (`3/8`), updating live as you kill or loot
- The marker disappears as soon as that objective is complete
- Works in combat
- Only tracks your own quests, not your party's
- Place the marker left of the health bar, right of it, or above the name, then fine-tune with offsets and scale

## Commands

| Command | What it does |
| --- | --- |
| `/eqp left` / `right` / `middle` | Where the marker sits on the nameplate |
| `/eqp toggle` | Turn markers on or off |
| `/eqp count` | Show or hide the progress count |
| `/eqp x <n>` / `/eqp y <n>` | Nudge the marker by pixels |
| `/eqp scale <0.5–3>` | Marker size |
| `/eqp reset` | Back to defaults |
